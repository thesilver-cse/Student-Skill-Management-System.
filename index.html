SkillTrack is a student skill management system designed to help students organize technical skills, monitor learning progress, and manage learning goals in one place.

Explore Source Code ↗ Explore Features ↓

What SkillTrack offers

A centralized place to organize and monitor learning.

🎯

Skill Management

Add, view, update, and remove skills while organizing them by category and proficiency.

📈

Progress Tracking

Record learning progress and monitor the status of your skills.

🗓️

Learning Goals

Create learning goals, set target dates, and track their completion status.

👤

Student Profile

Manage account details and access your learning information through a personal account.

Technology stack

Built with core Java web technologies.

Java JSP Java Servlets JDBC MySQL / MariaDB Apache Tomcat HTML & CSS JavaScript Bootstrap

How it works

The application's server-side architecture.

JSP / HTML → Servlet Controller → DAO → JDBC → Database

The project uses a traditional Java web architecture. This public page is a static showcase; it does not connect to the Java backend or database.
